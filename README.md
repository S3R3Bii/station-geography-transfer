# Station geography transfer

Under a fixed retrospective simulated cold-start test, the selected geographic model has held MAE **11.621 departures/day**, versus **21.047** for pooled weekday counts: **44.8% lower**. Two of the twelve held coordinate groups have worse errors. Recorded departures do not establish bike stock, dock availability or real relocation benefits.

The validation-only selection uses a 56-day weekday/weekend donor history, five neighbors and inverse-distance weights. All 54 configurations and the pooled baseline remain in the validation export. Twenty-four canonical dependencies were frozen before held analytical summaries. Immediate complete prior-day counts are an idealized assumption; actual public files were posted later.

Source, numerical and isolated-replay checks pass. Figures, manuscript, final publication audit and exact-head Linux/merge/tag proof remain pending, so this is not yet a completed study release.
